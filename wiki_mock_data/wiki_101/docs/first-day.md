# 第一天须知

恭喜您成为公司的一员！第一天可能会有些紧张，这份指南将帮助您轻松度过。

## 到达公司

### 上班时间
- **正式上班时间**：9:30 - 18:30
- **第一天建议**：9:00 到达，预留充足时间办理入职

### 交通指南
- **地铁**：3号线 × 科技园站 B 出口，步行 5 分钟
- **公交**：B987、M123 到 × 科技园站
- **停车**：地下停车场，凭员工卡免费

### 着装要求
- **日常**：商务休闲装（Smart Casual）
- **重要会议**：商务正装
- **周五**：休闲装（Casual Friday）

## 入职当天流程

### 9:00 - 9:30 前台报到
1. 到 1 楼前台说明来意
2. 前台会通知 HR 部门
3. 等待 HR 同事带您办理手续

### 9:30 - 11:00 人事手续
- 填写员工信息表
- 签署劳动合同
- 办理社保公积金
- 领取员工卡
- 拍摄员工照片

### 11:00 - 12:00 IT 配置
- 领取办公电脑和外设
- 配置企业邮箱
- 开通系统权限：
  - OA 系统
  - 考勤系统
  - GitLab / GitHub
  - Jira / Tapd
  - 企业微信

### 12:00 - 13:30 午餐时间
- **员工餐厅**：2 楼，凭员工卡享受补贴
- **附近餐厅**：B1 层有多家餐厅可选择
- **外卖**：可以点外卖到前台

### 13:30 - 15:00 团队见面
- 部门 Leader 介绍团队
- 认识团队成员
- 参观工位和工作区域
- 了解团队文化

### 15:00 - 17:00 Mentor 对接
- 与 Mentor 一对一沟通
- 了解工作内容和目标
- 讲解团队规范和流程
- 配置开发环境（技术岗位）

### 17:00 - 18:00 自由安排
- 整理工位
- 熟悉办公环境
- 安装必要软件
- 阅读团队文档

## 办公区域介绍

### 🏢 楼层分布
- **1F**：前台、接待区、展厅
- **2F**：员工餐厅、休息区、健身房
- **3F**：研发中心
- **4F**：产品与设计团队
- **5F**：市场与运营团队
- **6F**：管理层、会议室

### 🚻 生活设施
- **饮水区**：每层楼都有，提供热水、冷水、咖啡
- **休息室**：配有沙发、按摩椅、游戏机
- **母婴室**：6 楼，为哺乳期妈妈提供私密空间
- **医务室**：2 楼，配有常用药品

## 常用系统账号

第一天您会收到以下账号信息（通过企业邮箱发送）：

| 系统 | 用途 | 登录方式 |
|------|------|----------|
| 企业邮箱 | 邮件通讯 | yourname@company.com |
| OA 系统 | 审批流程 | SSO 单点登录 |
| 考勤系统 | 打卡请假 | 员工卡号 + 初始密码 |
| GitLab | 代码管理 | 企业邮箱 + 密码 |
| Jira | 项目管理 | SSO 单点登录 |

💡 **初始密码**：通常是 `Welcome123!`，首次登录后请修改。

## 第一天小贴士

✅ **要做的事**
- 微笑，保持开放和友好的态度
- 主动介绍自己
- 记住同事的名字（可以偷偷记笔记）
- 多问问题，不要不好意思
- 加入团队的微信群/企业微信群

❌ **避免做的事**
- 迟到（第一印象很重要）
- 在不了解团队文化前发表强烈意见
- 不懂装懂
- 午休时间打扰同事

## 紧急情况

🆘 **需要帮助时**
- 找您的 Mentor
- 联系 HR 部门（内线 8888）
- 前台（内线 1000）

🏥 **身体不适**
- 医务室：2 楼（内线 7777）
- 紧急情况：直接拨打 120
