# 入职流程

欢迎加入！以下是您的入职流程清单，请按照步骤完成。

## 入职前准备

### 1. 收到 Offer 后

- [ ] 签署并回传 Offer Letter
- [ ] 准备入职所需材料：
  - 身份证原件及复印件
  - 学历学位证书原件及复印件
  - 离职证明（如有）
  - 一寸照片 2 张
  - 银行卡复印件（用于工资发放）

### 2. 入职当天

- [ ] 上午 9:00 到前台报到
- [ ] 领取员工卡和工位钥匙
- [ ] 拍摄员工照片
- [ ] 填写个人信息表

## 入职第一周

### Day 1 - 报到与基础设置

- [ ] HR 部门办理入职手续
- [ ] IT 部门配置账号和设备
  - 企业邮箱
  - 办公电脑
  - 工作手机（如需要）
  - 各类系统权限
- [ ] 参加新员工欢迎会
- [ ] 团队 Leader 介绍团队成员

### Day 2-3 - 熟悉环境

- [ ] 参观办公区域
- [ ] 了解公司组织架构
- [ ] 学习使用内部系统
  - OA 系统
  - 考勤系统
  - 项目管理工具
- [ ] 阅读员工手册

### Day 4-5 - 融入团队

- [ ] 参加部门会议
- [ ] 了解当前项目情况
- [ ] 与 Mentor 一对一沟通
- [ ] 开始接手简单任务

## 入职第一月

### 第 1-2 周
- 完成新员工培训课程
- 熟悉业务流程和工作内容
- 参与团队例会和项目讨论

### 第 3-4 周
- 开始承担独立工作任务
- 与 Leader 进行阶段性沟通
- 参加公司活动，融入团队

## 重要提示

💡 **Mentor 制度**  
每位新员工都会有一位 Mentor 负责帮助您快速融入团队。有任何问题都可以随时向 Mentor 请教。

📅 **试用期**  
试用期为 3 个月，期间会有定期的工作反馈和评估。

📞 **紧急联系**  
- HR：内线 8888
- IT Support：内线 9999
- 行政：内线 7777
